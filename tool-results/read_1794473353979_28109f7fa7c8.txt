   117→   117→ * triedKeyIds: مفاتيح جُرِّبت داخل نفس سلسلة التنفيذ فتُتخطى (التبديل للأمام فقط).
   118→   118→ * كل محاولة تُسجَّل في attempts_json + عدّادات المفتاح.

   120→   120→async function attemptCreation(
   121→   121→  taskId: string,
   122→   122→  model: ModelDef,
   123→   123→  input: Record<string, unknown>,
   124→   124→  triedKeyIds: Set<string>
   125→   125→): Promise<CreateOutcome> {
   126→   126→  const pool = await getKeyPool(model.providers);
   127→   127→  // مزود بلا مفتاح (pollinations): يُضاف مصطنعًا في **آخر** الترتيب التسلسلي
   128→   128→  // ما لم يوجد مفتاح حقيقي له في القاعدة (لو تغيّرت سياستهم مستقبلًا وتطلب توكن)
   129→   129→  for (const p of model.providers) {
   130→   130→    if (!KEYLESS_PROVIDERS.has(p)) continue;
   131→   131→    if (pool.some((c) => c.provider === p)) continue;
   132→   132→    pool.push(syntheticKeyCandidate(p, pool.length));
   133→   133→  }
   134→   134→  for (const cand of pool) {
   135→   135→    if (triedKeyIds.has(cand.key.id)) continue;
   136→   136→    const adapter = ADAPTERS[cand.provider];
   137→   137→    if (!adapter) continue;
   138→   138→    const providerModel = model.providerModel[cand.provider as ProviderId] ?? "";
   139→   139→    const keyRef: ProviderKeyRef = {
   140→   140→      id: cand.key.id,
   141→   141→      api_key: cand.key.api_key,
   142→   142→      label: cand.key.label || "",
   143→   143→    };
   144→   144→
   145→   145→    // تسجيل المحاولة دائمًا — نجاحًا أو فشلًا
   146→   146→    const attempt: TaskAttempt = {
   147→   147→      provider: cand.provider,
   148→   148→      keyId: cand.key.id,
   149→   149→      keyLabel: cand.key.label || "",
   150→   150→      ok: false,
   151→   151→      at: new Date().toISOString(),
   152→   152→    };
   153→   153→
   154→   154→    try {
   155→   155→      if (model.type === "image" && adapter.createImageSync) {
   156→   156→        // صور متزامنة (CometAPI / Pollinations): النتيجة فورية
   157→   157→        const { urls } = await adapter.createImageSync(keyRef, providerModel, input as never);
   158→   158→        attempt.ok = true;
   159→   159→        await updateTask(taskId, { attempts: [attempt] });
   160→   160→        if (!cand.synthetic) await recordKeySuccess(cand.key);
   161→   161→        return { ok: true, provider: cand.provider as TaskProvider, keyId: cand.key.id, syncUrls: urls };
   162→   162→      }
   163→   163→      const { providerTaskId } = await adapter.createTask(keyRef, providerModel, input as never);
   164→   164→      attempt.ok = true;
   165→   165→      await updateTask(taskId, {
   166→   166→        attempts: [attempt],
   167→   167→        provider: cand.provider,
   168→   168→        provider_task_id: providerTaskId,
   169→   169→        key_id: cand.key.id,
   170→   170→        status: "processing",
   171→   171→        progress: 5,
   172→   172→      });
   173→   173→      if (!cand.synthetic) await recordKeySuccess(cand.key);
   174→   174→      return { ok: true, provider: cand.provider as TaskProvider, keyId: cand.key.id };
   175→   175→    } catch (e) {
   176→   176→      const pe = e as ProviderError;
   177→   177→      const errClass: ErrorClass =
   178→   178→        pe && typeof pe === "object" && "class" in pe ? (pe.class as ErrorClass) : classifyProviderError(0, String(pe));
   179→   179→      const msg = pe instanceof Error ? pe.message : String(pe);
   180→   180→      attempt.ok = false;
   181→   181→      attempt.errorClass = errClass;
   182→   182→      attempt.error = msg.slice(0, 300);
   183→   183→      await updateTask(taskId, { attempts: [attempt] });
   184→   184→      if (!cand.synthetic) await recordKeyFailure(cand.key, errClass, msg);
   185→   185→
   186→   186→      if (errClass === "params") {
   187→   187→        // خطأ معطيات — تبديل المفاتيح لن يحلّه: توقف فورًا بفشل حقيقي
   188→   188→        await updateTask(taskId, {
   189→   189→          status: "failed",
   190→   190→          error_message: clientSafeError(msg),
   191→   191→        });
   192→   192→        return { ok: false };
   193→   193→      }
   194→   194→      // disabled / exhausted / provider / temporary ⇒ الانتقال للمفتاح التالي بصمت
   195→   195→      triedKeyIds.add(cand.key.id);
   196→   196→      continue;
   197→   197→    }
   198→   198→  }
   199→   199→  return { ok: false };
   200→   200→}

   205→   205→
   206→   206→async function pollOnce(
   207→   207→  task: TaskRow,
   208→   208→  model: ModelDef
   209→   209→): Promise<{ done: boolean; failed: boolean; urls?: string[] }> {
   210→   210→  if (!task.provider_task_id || !task.key_id) return { done: false, failed: false };
   211→   211→  const keyRow = await getApiKey(task.key_id);
   212→   212→  if (!keyRow) return { done: false, failed: false };
   213→   213→  const adapter = ADAPTERS[task.provider ?? ""];
   214→   214→  if (!adapter) return { done: false, failed: false };
   215→   215→  const providerModel = model.providerModel[task.provider as ProviderId] ?? "";
   216→   216→
   217→   217→  try {
   218→   218→    const r = await adapter.checkTask(
   219→   219→      { id: keyRow.id, api_key: keyRow.api_key, label: keyRow.label || "" },
   220→   220→      task.provider_task_id,
   221→   221→      providerModel
   222→   222→    );
   223→   223→    if (r.status === "completed" && r.urls?.length) {
   224→   224→      await recordKeySuccess(keyRow);
   225→   225→      await updateTask(task.id, {
   226→   226→        status: "completed",
   227→   227→        progress: 100,
   228→   228→        result_urls: r.urls,
   229→   229→      });
   230→   230→      return { done: true, failed: false, urls: r.urls };
   231→   231→    }
   232→   232→    await updateTask(task.id, { progress: r.progress ?? task.progress });
   233→   233→    return { done: false, failed: false };
   234→   234→  } catch (e) {
   235→   235→    const pe = e as ProviderError;
   236→   236→    const msg = pe instanceof Error ? pe.message : String(pe);
   237→   237→    const errClass: ErrorClass =
   238→   238→      pe && typeof pe === "object" && "class" in pe ? (pe.class as ErrorClass) : classifyProviderError(0, msg);
   239→   239→
   240→   240→    // فشل منتصف المهمة برسالة بنمط مفتاح/رصيد ⇒ تبديل صامت (4.3.2)
   241→   241→    const isKeyLike = KEY_FAIL_PATTERN.test(msg) || errClass === "disabled" || errClass === "exhausted";
   242→   242→    if (isKeyLike) {
   243→   243→      await recordKeyFailure(keyRow, errClass === "provider" ? "temporary" : errClass, msg);
   244→   244→      // إزالة الربط الحالي لإعادة الإنشاء على مفتاح آخر بنفس task_id
   245→   245→      await updateTask(task.id, {
   246→   246→        provider: null,
   247→   247→        provider_task_id: null,
   248→   248→        key_id: null,
   249→   249→        status: "processing",
   250→   250→        error_message: "بانتظار توفر مفتاح صالح…",
   251→   251→      });
   252→   252→      return { done: false, failed: false, urls: undefined };
   253→   253→    }
   254→   254→    if (errClass === "params") {
   255→   255→      await updateTask(task.id, { status: "failed", error_message: clientSafeError(msg) });
   256→   256→      return { done: false, failed: true };
   257→   257→    }
   258→   258→    if (errClass === "provider") {
   259→   259→      // فشل حقيقي من المزود (سياسة/محتوى/موديل) وليس مشكلة مفتاح
   260→   260→      await updateTask(task.id, { status: "failed", error_message: clientSafeError(msg) });
   261→   261→      return { done: false, failed: true };
   262→   262→    }
   263→   263→    // temporary — نستمر بالاستعلام
   264→   264→    return { done: false, failed: false };
   265→   265→  }
   266→   266→}

   268→   268→/**
   269→   269→ * التوليد: تسجيل المهمة ثم تجربة المفاتيح بالترتيب ثم نافذة انتظار ببث تقدم.
   270→   270→ * يعيد المهمة النهائية (مكتملة) أو مهمة processing يتابعها العميل بـ get_task.
   271→   271→ */
   272→   272→export async function runGeneration(opts: {
   273→   273→  model: ModelDef;
   274→   274→  params: {
   275→   275→    prompt: string;
   276→   276→    aspect_ratio?: string;
   277→   277→    resolution?: string;
   278→   278→    background?: string;
   279→   279→    output_format?: string;
   280→   280→    image_url?: string;
   281→   281→    enable_audio?: boolean;
   282→   282→    duration?: number;
   283→   283→  };
   284→   284→  wait_seconds?: number;
   285→   285→  onProgress?: ProgressCb;
   286→   286→}): Promise<TaskRow> {
   287→   287→  const { model, params } = opts;
   288→   288→  const defaultWait = model.type === "image" ? 90 : 25;
   289→   289→  const waitSeconds = clampWait(opts.wait_seconds, defaultWait);
   290→   290→
   291→   291→  // بناء input المعطيات الأصلية (تُخزَّن لإعادة الإنشاء عند التبديل)
   292→   292→  const input: Record<string, unknown> = { prompt: params.prompt };
   293→   293→  if (params.aspect_ratio) input.aspect_ratio = params.aspect_ratio;
   294→   294→  if (params.resolution) input.resolution = params.resolution;
   295→   295→  if (params.background) input.background = params.background;
   296→   296→  if (params.output_format) input.output_format = params.output_format;
   297→   297→  if (params.image_url) input.image_url = params.image_url;
   298→   298→  if (typeof params.enable_audio === "boolean") input.enable_audio = params.enable_audio;
   299→   299→  if (typeof params.duration === "number") input.duration = params.duration;
   300→   300→
   301→   301→  // تسجيل المهمة قبل أي نداء خارجي (حتى لو انقطع الاتصال تبقى قابلة للتتبع)
   302→   302→  const taskId = randomUUID();
   303→   303→  await insertTask({
   304→   304→    id: taskId,
   305→   305→    model: model.canonical,
   306→   306→    type: model.type,
   307→   307→    prompt: params.prompt,
   308→   308→    params: input,
   309→   309→    status: "pending",
   310→   310→  });
   311→   311→
   312→   312→  // تجربة المفاتيح بالترتيب التسلسلي الصارم
   313→   313→  const tried = new Set<string>();
   314→   314→  const outcome = await attemptCreation(taskId, model, input, tried);
   315→   315→
   316→   316→  if (!outcome.ok) {
   317→   317→    const still = await getTask(taskId);
   318→   318→    if (still && still.status !== "failed") {
   319→   319→      // بقيت processing برسالة داخلية — تُعاد محاولتها مع كل get_task
   320→   320→      await updateTask(taskId, {
   321→   321→        status: "processing",
   322→   322→        error_message: "بانتظار توفر مفتاح صالح…",
   323→   323→        params_merge: { _lastCreateAttempt: new Date().toISOString() },
   324→   324→      });
   325→   325→    }
   326→   326→    return (await getTask(taskId))!;
   327→   327→  }
   328→   328→
   329→   329→  // صور متزامنة اكتملت فورًا
   330→   330→  if (outcome.syncUrls?.length) {
   331→   331→    await updateTask(taskId, {
   332→   332→      provider: outcome.provider,
   333→   333→      key_id: outcome.keyId,
   334→   334→      status: "completed",
   335→   335→      progress: 100,
   336→   336→      result_urls: outcome.syncUrls,
   337→   337→    });
   338→   338→    return (await getTask(taskId))!;
   339→   339→  }
   340→   340→
   341→   341→  // نافذة الانتظار: استعلام كل 3 ثوانٍ + بث تقدم
   342→   342→  let task = await getTask(taskId)!;
   343→   343→  const deadline = Date.now() + waitSeconds * 1000;
   344→   344→  while (Date.now() < deadline) {
   345→   345→    await sleep(POLL_INTERVAL_MS);
   346→   346→    task = (await getTask(taskId))!;
   347→   347→    if (task.status === "completed" || task.status === "failed") return task;
   348→   348→
   349→   349→    // لم تُنشأ لدى المزود بعد (فشل كل المفاتيح سابقًا) — نعيد المحاولة داخل النافذة
   350→   350→    if (!task.provider_task_id) {
   351→   351→      const again = await attemptCreation(taskId, model, input, new Set());
   352→   352→      if (again.syncUrls?.length) {
   353→   353→        await updateTask(taskId, { status: "completed", progress: 100, result_urls: again.syncUrls });
   354→   354→        return (await getTask(taskId))!;
   355→   355→      }
   356→   356→      continue;
   357→   357→    }
   358→   358→
   359→   359→    const r = await pollOnce(task, model);
   360→   360→    if (r.done) return (await getTask(taskId))!;
   361→   361→    if (r.failed) return (await getTask(taskId))!;
   362→   362→
   363→   363→    const fresh = await getTask(taskId)!;
   364→   364→    const pct = fresh?.progress ?? 0;
   365→   365→    await opts.onProgress?.(
   366→   366→      pct,
   367→   367→      fresh && !fresh.provider_task_id
   368→   368→        ? "بانتظار توفر مفتاح صالح… جارٍ إعادة المحاولة تلقائيًا"
   369→   369→        : `قيد التوليد… ${pct}%`
   370→   370→    );
   371→   371→  }
   372→   372→  // انتهت النافذة دون نتيجة ⇒ processing ويكملها العميل بـ get_task
   373→   373→  return (await getTask(taskId))!;
   374→   374→}

   379→   379→
   380→   380→/** إعادة إنشاء مهمة بلا ربط حالي (فشلت كل المفاتيح سابقًا) بعد تهدئة 45 ثانية */
   381→   381→async function retryPendingCreation(task: TaskRow): Promise<TaskRow> {
   382→   382→  let meta: Record<string, unknown> = {};
   383→   383→  try {
   384→   384→    meta = JSON.parse(task.params_json || "{}");

   403→   403→export async function refreshTask(taskId: string): Promise<TaskRow | null> {
   404→   404→  const task = await getTask(taskId);
   405→   405→  if (!task) return null;
   406→   406→  if (task.status === "completed" || task.status === "failed") return task;
   407→   407→
   408→   408→  // دمج / تعليق مصوّر: منطق merger مستقل — نفرّق بالموديل
   409→   409→  if (task.provider === "merger") {
   410→   410→    return task.model === SLIDESHOW_MODEL ? refreshSlideshowTask(task) : refreshMergeTask(task);
   411→   411→  }
   412→   412→
   413→   413→  // لم تُنشأ بعد لدى المزود ⇒ إعادة محاولة الإنشاء (بتهدئة)
   414→   414→  if (!task.provider_task_id || !task.key_id) {

   426→   426→  // لأن التهدئة تخص فقط إعادة المحاولة عند «عدم توفر أي مفتاح»، لا التبديل الحي)

   431→   431→    });
   432→   432→    return retryPendingCreation(fresh);
   433→   433→  }
   434→   434→  return fresh;

   496→   496→  task_ids?: string[];

   498→   498→  onProgress?: ProgressCb;
   499→   499→}): Promise<MergeOutcome> {

   501→   501→  const failedRefs: string[] = [];
   502→   502→

   511→   511→      const arr = JSON.parse(t.result_urls_json) as string[];

   513→   513→    } catch {

   515→   515→    }
   516→   516→  }
   517→   517→  // 2) ثم الروابط المباشرة بنفس ترتيبها
   518→   518→  for (const u of opts.urls ?? []) urls.push(u.trim());

   521→   521→    return {
   522→   522→      error:
   523→   523→        "❌ الدمج يحتاج مقطعَين على الأقل. مرّر urls (روابط مباشرة) أو task_ids لمهام مكتملة." +
   524→   524→        (failedRefs.length ? `\nتفاصيل: ${failedRefs.join(" | ")}` : ""),
   525→   525→    };
   526→   526→  }
   527→   527→  if (failedRefs.length) {
   528→   528→    return { error: `❌ تعذّر حل بعض المعرفات للدمج: ${failedRefs.join(" | ")}` };
   529→   529→  }
   530→   530→  if (urls.length > 10) {
   531→   531→    return { error: "❌ أقصى عدد مقاطع للدمج هو 10 (خدمة الدمج تقبل 10 مقاطع كحد أقصى)." };
   532→   532→  }
   533→   533→  // روابط مباشرة عامة فقط
   534→   534→  for (const u of urls) {
   535→   535→    if (!/^https?:\/\//i.test(u)) {
   536→   536→      return { error: `❌ كل المقاطع يجب أن تكون روابط http/https مباشرة وعامة — رفض: ${u.slice(0, 120)}` };
   537→   537→    }
   538→   538→  }
   539→   539→
   540→   540→  // تسجيل المهمة أولًا ثم النداء على الخدمة
   541→   541→  const taskId = randomUUID();

   543→   543→    id: taskId,
   544→   544→    provider: "merger",
   545→   545→    model: "video-merger",
   546→   546→    type: "merge",
   547→   547→    prompt: `دمج ${urls.length} مقاطع`,
   548→   548→    params: { videos: urls },
   549→   549→    status: "processing",
   550→   550→  });
   551→   551→
   552→   552→  let jobId: string;
   553→   553→  try {
   554→   554→    const created = await createMergerJob(urls);
   555→   555→    jobId = created.jobId;
   556→   556→  } catch (e) {
   557→   557→    const pe = e as ProviderError;
   558→   558→    const terminal = (pe as ProviderError & { mergerTerminal?: boolean }).mergerTerminal === true;
   559→   559→    if (terminal) {
   560→   560→      await updateTask(taskId, { status: "failed", error_message: clientSafeError(pe.message) });
   561→   561→      return { task: await getTask(taskId) };
   562→   562→    }
   563→   563→    // شبكتنا نحن — تبقى processing وتُعاد المحاولة مع get_task
   564→   564→    await updateTask(taskId, {
   565→   565→      status: "processing",
   566→   566→      error_message: "تعذر إنشاء مهمة الدمج الآن — ستُعاد المحاولة تلقائيًا مع get_task",
   567→   567→      params_merge: { _lastCreateAttempt: new Date().toISOString(), _videos: urls },
   568→   568→    });
   569→   569→    return { task: await getTask(taskId) };
   570→   570→  }
   571→   571→
   572→   572→  await updateTask(taskId, { provider_task_id: jobId, status: "processing", progress: 5 });
   573→   573→  await fireProcessOnce(taskId, jobId, "merge");
   574→   574→
   575→   575→  // نافذة الانتظار الافتراضية 60 ثانية — استعلام كل 3 ثوانٍ وكتابة الحالة فورًا
   576→   576→  const waitSeconds = clampWait(opts.wait_seconds, 60);
   577→   577→  const deadline = Date.now() + waitSeconds * 1000;
   578→   578→  while (Date.now() < deadline) {
   579→   579→    await sleep(POLL_INTERVAL_MS);
   580→   580→    let st: MergerJobState;
   581→   581→    try {
   582→   582→      st = await getMergerJob(jobId);
   583→   583→    } catch (e) {
   584→   584→      const pe = e as ProviderError;
   585→   585→      if ((pe as ProviderError & { mergerTerminal?: boolean }).mergerTerminal) {
   586→   586→        // 404/فشل معلن من الخدمة = نهائي (لكن إن لم يبدأ process بعد فقد استُدعي الآن فورًا)
   587→   587→        await updateTask(taskId, { status: "failed", error_message: clientSafeError(pe.message) });
   588→   588→        return { task: await getTask(taskId) };
   589→   589→      }
   590→   590→      continue; // شبكتنا نحن — نستمر حتى نهاية النافذة
   591→   591→    }
   592→   592→    const r = await applyMergerState(taskId, st);
   593→   593→    if (r === "done" || r === "failed") return { task: await getTask(taskId) };
   594→   594→    await opts.onProgress?.(st.progress, `جارٍ الدمج… ${st.progress}%`);
   595→   595→  }
   596→   596→  return { task: await getTask(taskId) };
   597→   597→}

   695→   695→ * حد المعدل المجاني (صورة كل ~45 ث/‏IP) يُعالج بانتظار retryAfterMs حتى سقف waitSeconds.
   696→   696→ */
   697→   697→async function resolveImageUrls(
   698→   698→  items: string[],
   699→   699→  aspect: string,
   700→   700→  waitSeconds: number,
   701→   701→  onProgress?: ProgressCb
   702→   702→): Promise<string[]> {
   703→   703→  const imageModel = modelByCanonical("gpt-image-2-6/flare-text-to-image");
   704→   704→  if (!imageModel) throw new Error("موديل الصور غير معرّف");
   705→   705→  const deadline = Date.now() + waitSeconds * 1000;
   706→   706→  const prompts = items.filter((i) => !/^https?:\/\//i.test(i)).length;
   707→   707→  const urls: string[] = [];
   708→   708→  let generated = 0;
   709→   709→
   710→   710→  for (let idx = 0; idx < items.length; idx++) {
   711→   711→    const item = items[idx].trim();
   712→   712→    if (/^https?:\/\//i.test(item)) {
   713→   713→      urls.push(item);
   714→   714→      continue;
   715→   715→    }
   716→   716→    let done = false;
   717→   717→    let lastErr = "";
   718→   718→    while (!done && Date.now() < deadline) {
   719→   719→      const pool = await getKeyPool(imageModel.providers);
   720→   720→      for (const p of imageModel.providers) {
   721→   721→        if (!KEYLESS_PROVIDERS.has(p)) continue;
   722→   722→        if (pool.some((c) => c.provider === p)) continue;
   723→   723→        pool.push(syntheticKeyCandidate(p, pool.length));
   724→   724→      }
   725→   725→      let retriable = false;
   726→   726→      for (const cand of pool) {
   727→   727→        const adapter = ADAPTERS[cand.provider];
   728→   728→        if (!adapter?.createImageSync) continue;
   729→   729→        const providerModel = imageModel.providerModel[cand.provider as ProviderId] ?? "";
   730→   730→        try {
   731→   731→          const { urls: u } = await adapter.createImageSync(
   732→   732→            { id: cand.key.id, api_key: cand.key.api_key, label: cand.key.label || "" },
   733→   733→            providerModel,
   734→   734→            { prompt: item, aspect_ratio: aspect }
   735→   735→          );
   736→   736→          if (u.length) {
   737→   737→            urls.push(u[0]);
   738→   738→            done = true;
   739→   739→          }
   740→   740→          break;
   741→   741→        } catch (e) {
   742→   742→          const pe = e as ProviderError;
   743→   743→          const cls: ErrorClass =
   744→   744→            pe && typeof pe === "object" && "class" in pe
   745→   745→              ? (pe.class as ErrorClass)
   746→   746→              : classifyProviderError(0, String(pe));
   747→   747→          lastErr = pe instanceof Error ? pe.message : String(pe);
   748→   748→          if (cls === "temporary") {
   749→   749→            const wait = Math.min(
   750→   750→              (pe as ProviderError & { retryAfterMs?: number }).retryAfterMs ?? 8_000,
   751→   751→              Math.max(1_000, deadline - Date.now())
   752→   752→            );
   753→   753→            await sleep(wait);
   754→   754→            retriable = true;
   755→   755→            break; // أعد المحاولة من أول الترتيب بعد الانتظار
   756→   756→          }
   757→   757→          // disabled/exhausted/provider ⇒ المزود التالي فورًا
   758→   758→          continue;
   759→   759→        }
   760→   760→      }
   761→   761→      if (!done && !retriable && Date.now() < deadline) {
   762→   762→        // كل المزودين فشلوا بأخطاء غير مؤقتة — لا فائدة من مواصلة الانتظار
   763→   763→        throw new Error(`تعذر توليد الصورة ${generated + 1}: ${clientSafeError(lastErr)}`);
   764→   764→      }
   765→   765→    }
   766→   766→    if (!done) {
   767→   767→      throw new Error(
   768→   768→        `انتهى وقت تجهيز الصور قبل الاكتمال — الوصول المجاني يسمح بصورة كل ~45 ثانية (${prompts} صور نصية ≈ ${prompts * 45} ث). ` +
   769→   769→          `الحلول: مرّر روابط صور جاهزة بدل الأوصاف، أو قلّل عدد الصور، أو زد wait_seconds حتى 240.`
   770→   770→      );
   771→   771→    }
   772→   772→    generated++;
   773→   773→    await onProgress?.(
   774→   774→      Math.round((generated / prompts) * 100),
   775→   775→      `تجهيز الصور ${generated}/${prompts}…`
   776→   776→    );
   777→   777→  }
   778→   778→  return urls;
   779→   779→}

   786→   786→/** فيديو تعليق مصوّر: صور (روابط أو أوصاف) + نص راوي أو صوت جاهز */
   787→   787→export async function runSlideshow(opts: {
   788→   788→  images: string[];
   789→   789→  narration_text?: string;
   790→   790→  audio_url?: string;
   791→   791→  voice_lang?: string;
   792→   792→  per_image_seconds?: number;
   793→   793→  resolution?: string;
   794→   794→  aspect_ratio?: string;
   795→   795→  wait_seconds?: number;
   796→   796→  onProgress?: ProgressCb;
   797→   797→}): Promise<SlideshowOutcome> {
   798→   798→  const images = (opts.images ?? []).map((s) => String(s || "").trim()).filter(Boolean);
   799→   799→  if (images.length < 1) return { error: "❌ مرّر صورة واحدة على الأقل — رابط مباشر أو وصف نصي لتوليدها." };
   800→   800→  if (images.length > 20) return { error: "❌ أقصى عدد صور هو 20." };
   801→   801→  const narration = (opts.narration_text || "").trim();
   802→   802→  const audioUrl = (opts.audio_url || "").trim();
   803→   803→  if (!narration && !audioUrl) {
   804→   804→    return { error: "❌ مرّر نص التعليق الصوتي narration_text أو رابط صوت جاهز audio_url." };
   805→   805→  }
   806→   806→  if (narration && audioUrl) {
   807→   807→    return { error: "❌ مرّر narration_text أو audio_url — ليس الاثنين معًا." };
   808→   808→  }
   809→   809→  if (narration.length > 8000) return { error: "❌ نص التعليق طويل جدًا (الحد 8000 حرف)." };
   810→   810→  const aspect = ["16:9", "9:16", "1:1"].includes(opts.aspect_ratio || "") ? opts.aspect_ratio! : "16:9";
   811→   811→  const resolution = ["480p", "720p", "1080p"].includes(opts.resolution || "") ? opts.resolution! : "720p";
   812→   812→
   813→   813→  const taskId = randomUUID();
   814→   814→  await insertTask({
   815→   815→    id: taskId,
   816→   816→    provider: "merger",
   817→   817→    model: SLIDESHOW_MODEL,
   818→   818→    type: "video",
   819→   819→    prompt: narration ? `تعليق مصوّر: ${narration.slice(0, 80)}` : `تعليق مصوّر (${images.length} صور بصوت جاهز)`,
   820→   820→    params: { images, narration_text: narration, audio_url: audioUrl, aspect_ratio: aspect, resolution },
   821→   821→    status: "processing",
   822→   822→  });
   823→   823→
   824→   824→  // 1) تجهيز روابط الصور (توليد للنصوص)
   825→   825→  let urls: string[];
   826→   826→  try {
   827→   827→    const waitSeconds = clampWait(opts.wait_seconds, 120);
   828→   828→    urls = await resolveImageUrls(images, aspect, waitSeconds, opts.onProgress);
   829→   829→  } catch (e) {
   830→   830→    const msg = e instanceof Error ? e.message : String(e);
   831→   831→    await updateTask(taskId, { status: "failed", error_message: clientSafeError(msg) });
   832→   832→    return { task: await getTask(taskId) };
   833→   833→  }
   834→   834→
   835→   835→  // 2) إنشاء المهمة في خدمة الدمج
   836→   836→  let jobId: string;
   837→   837→  try {
   838→   838→    const created = await createMergerSlideshow({
   839→   839→      images: urls,
   840→   840→      narration_text: narration || undefined,
   841→   841→      audio_url: audioUrl || undefined,
   842→   842→      voice_lang: opts.voice_lang || "ar",
   843→   843→      per_image_seconds: opts.per_image_seconds,
   844→   844→      resolution,
   845→   845→      aspect_ratio: aspect,
   846→   846→    });
   847→   847→    jobId = created.jobId;
   848→   848→  } catch (e) {
   849→   849→    const pe = e as ProviderError;
   850→   850→    const terminal = (pe as ProviderError & { mergerTerminal?: boolean }).mergerTerminal === true;
   851→   851→    if (terminal) {
   852→   852→      await updateTask(taskId, { status: "failed", error_message: clientSafeError(pe.message) });
   853→   853→      return { task: await getTask(taskId) };
   854→   854→    }
   855→   855→    await updateTask(taskId, {
   856→   856→      status: "processing",
   857→   857→      error_message: "تعذر إنشاء مهمة التعليق الآن — ستُعاد المحاولة تلقائيًا مع get_task",
   858→   858→      params_merge: { _lastCreateAttempt: new Date().toISOString(), _slideshow: { images: urls, narration_text: narration, audio_url: audioUrl, voice_lang: opts.voice_lang || "ar", per_image_seconds: opts.per_image_seconds, resolution, aspect_ratio: aspect } },
   859→   859→    });
   860→   860→    return { task: await getTask(taskId) };
   861→   861→  }
   862→   862→
   863→   863→  await updateTask(taskId, { provider_task_id: jobId, status: "processing", progress: 5 });
   864→   864→  await fireProcessOnce(taskId, jobId, "slideshow");
   865→   865→
   866→   866→  // 3) نافذة انتظار مع بث التقدم
   867→   867→  const waitSeconds = clampWait(opts.wait_seconds, 120);
   868→   868→  const deadline = Date.now() + waitSeconds * 1000;
   869→   869→  while (Date.now() < deadline) {
   870→   870→    await sleep(POLL_INTERVAL_MS);
   871→   871→    let st: MergerJobState;
   872→   872→    try {
   873→   873→      st = await getMergerSlideshow(jobId);
   874→   874→    } catch (e) {
   875→   875→      const pe = e as ProviderError;
   876→   876→      if ((pe as ProviderError & { mergerTerminal?: boolean }).mergerTerminal) {
   877→   877→        await updateTask(taskId, { status: "failed", error_message: clientSafeError(pe.message) });
   878→   878→        return { task: await getTask(taskId) };
   879→   879→      }
   880→   880→      continue;
   881→   881→    }
   882→   882→    const r = await applyMergerState(taskId, st);
   883→   883→    if (r === "done" || r === "failed") return { task: await getTask(taskId) };
   884→   884→    await opts.onProgress?.(st.progress, `بناء الفيديو… ${st.progress}%`);
   885→   885→  }
   886→   886→  return { task: await getTask(taskId) };
   887→   887→}
